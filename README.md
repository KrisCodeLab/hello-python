# Python Wissensdatenbank

Eine strukturierte und umfassende Sammlung von Jupyter Notebooks als Nachschlagewerk und Lernhilfe für die Anwendungsentwicklung in Python.

<b><u>#### Die Wissensdatenbank ist aktuell nicht zu 100% vollständig, einzelne Themengebiete werden noch ausgearbeitet! ####</u></b>

## Inhaltsverzeichnis und Struktur

Das Projekt ist modular aufgebaut und behandelt fundamentale sowie fortgeschrittene Themen der Programmierung:

* **Modul 1:** Fundament, Syntax & Best Practices (PEP8, Kommentare, Operatoren)
* **Modul 2:** Variablen und Datentypen (Zahlen, Strings, Formatierung)
* **Modul 3:** Kontrollstrukturen (If-Anweisungen, Schleifen, Exception Handling)
* **Modul 4:** Datenstrukturen (Listen, Tupel, Dictionaries, Sets)
* **Modul 5:** Funktionen, Generatoren & Module
* **Modul 6:** Objektorientierte Programmierung (Klassen, Vererbung, Polymorphie, MRO)
* **Modul 7:** Data Science Grundlagen (Datum & Zeit, Numpy)
* **Modul 8:** Algorithmen (Suchverfahren, Sortieralgorithmen, O-Notation)
* **Modul 9:** Praxis & Workbooks (Eigenständige Übungsaufgaben)

## Voraussetzungen und Nutzung

Um die Notebooks optimal ausführen zu können, wird folgende Einrichtung empfohlen:
* **Umgebung:** Ein lokales Virtual Environment (`.venv`)
* **Abhängigkeiten:** Pakete wie `opencv-python` oder `numpy` sollten innerhalb des Virtual Environments installiert werden.

## Ausführung
1. Das Repository klonen oder als ZIP herunterladen.
2. Ein Virtual Environment im Projektordner erstellen und aktivieren.
3. Die Notebooks in einer Jupyter-kompatiblen Umgebung nach Wahl öffnen.
4. Sicherstellen, dass als Kernel das lokale Virtual Environment ausgewählt ist.
